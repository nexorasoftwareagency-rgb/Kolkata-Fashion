Build a complete modern mobile first fashion ecommerce frontend demo for a local retail garments shop named Kolkata Fashion Parsa located in Parsa Bihar India.

The design language should combine:
Meesho’s Bharat friendly shopping simplicity,
Flipkart’s structured ecommerce UX,
and Myntra style fashion presentation.

The website should feel:
clean,
fast,
smooth,
trustworthy,
fashion focused,
premium but affordable.

IMPORTANT:
This is ONLY a frontend ecommerce demo.
Do not build backend, authentication, payment gateway, real cart system, or APIs.

TECH STACK:
Use React with modern component structure.
Use Tailwind CSS for styling.
Use responsive mobile first design.
Use reusable components.
Use clean ecommerce architecture.

OVERALL DESIGN STYLE:
Minimal ecommerce UI.
Large spacing.
Rounded cards.
Soft shadows.
Smooth hover transitions.
Fast loading feel.
Professional fashion aesthetics.
Indian ecommerce style UX.
Modern typography.

COLOR PALETTE:
Primary:
White

Secondary:
Black

Accent:
Flipkart blue and Meesho pink inspired subtle accents.

Do NOT overuse bright colors.
Keep the design elegant and lightweight.

TYPOGRAPHY:
Use Poppins font.
Modern ecommerce typography hierarchy.
Readable mobile typography.
